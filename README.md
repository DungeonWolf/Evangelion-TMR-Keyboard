What is a TMR Keyboard?
Similar to a hall effect keyboard and unlike an analog keyboard, TMR and Hall Effect Keyboards usually use magnets to detect whether a key is pressed down. Think of it being similar to pressing 
a button versus pressing down a scale, but once the scale gets to a certain weight, it activates something else. That is also why they are better than analog, because you can adjust where that 
activation point is.
